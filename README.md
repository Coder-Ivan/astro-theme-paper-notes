# Paper Notes · 山页手记

把 Markdown 或 Joplin 笔记做成一本可以翻阅、检索的网上手记。首页带有山景题头，文章页沿用格纸背景、站主侧栏和随阅读位置更新的章节目录。默认构建生成静态 HTML；需要私有日记和讨论区时，可以启用同一套主题自带的 Node.js 服务。

第一次使用，可以跟着这篇中文教程从创建仓库做到发布第一篇文章。[山页手记 Astro 主题使用指南：从 GitHub 模板到自己的博客](https://blog.lifan.run/posts/astro-github-73968b0137a1/)

## 五分钟启动

1. 点击 **[Use this template](https://github.com/new?template_name=astro-theme-paper-notes&template_owner=Coder-Ivan)**，选择自己的仓库名和可见性。也可以在仓库的 **Code → Download ZIP** 下载源码。
2. 克隆自己刚创建的仓库，或解压 ZIP。在包含 `package.json` 的目录打开终端，使用 Node.js 24 和 npm。
3. 运行以下两条命令，打开终端显示的本地地址，默认是 `http://127.0.0.1:4321/`。项目自带示例笔记和图片。

```sh
npm ci
npm run dev
```

打开一篇文章可以试用章节目录和「继续阅读」链接。点击导航中的搜索，或按 ⌘K / Ctrl+K 搜索全文。结果支持方向键、回车和 Esc。缩窄窗口后可以展开文章目录。

## 换成自己的站点

编辑根目录的 `theme.config.mjs`，保存后重启开发服务。

| 设置 | 用法 |
| --- | --- |
| `title`、`description` | 首页标题、站名和站点简介 |
| `author` | 设置姓名、简介、邮箱、头像。留空邮箱可隐藏联系入口，留空头像会显示名字的首字 |
| `accent` | 链接及部分控件的强调色，例如 `#805338` |
| `heroImage` | 将封面放在 `public/images/`，填入 `/images/文件名.webp`。留空时显示 CSS 绘制的山景 |
| `site` | 上线后填写网站地址，例如 `https://notes.example.org`，用于生成规范网址 |
| `services` | 默认 `false`。启用账号、私有日记和评论时改为 `true`，按下文启动服务 |

编辑 `src/styles/site.css` 可调整色板、字体、卡片和布局。导航在 `src/layouts/Shell.astro`，作者资料卡在 `src/components/Sidebar.astro`，文章目录的外观在 `src/styles/article-outline.css`。

## 写文章与导入 Joplin

把 Markdown 放进 `content/`，用目录组织分类。例如，`content/旅行/海边/傍晚的海岸.md` 会把文章列在「旅行 → 海边」下。也可以在 Front Matter 里指定完整路径，例如 `notebookPath: [观察手册, 测量方法]`。导入 Joplin 时，保留导出目录的笔记本层级即可。标签取自文章的 Front Matter。给文章取一个固定的 `slug`，以后移动文件或改标题仍能沿用原网址。

打开 `/categories/` 时，一级笔记本默认展开，二级及更深的笔记本默认收起。点击分类名可独立展开或收起。每篇文章只列在直属分类下，分类旁的篇数包含所有下级分类的公开文章。直接访问子分类书签会展开目标及其上级。

首页和后续分页的文章卡片会在日期旁显示完整笔记本路径，打开文章后，标题下方也有同一条路径。例如，《三次读数的中间值》显示「观察手册 › 测量方法」。点击「观察手册」可浏览整个一级分类，点击「测量方法」会直接展开并定位到这个子分类。

```md
---
title: 傍晚的海岸
date: 2025-06-08
slug: evening-coast
tags: [散步, 观察]
---

## 从栈桥出发

潮水退下去时，沙上留着一条细线。
```

正文支持表格、KaTeX 公式、Mermaid 代码块、图片和 Markdown 笔记互链。引用图片可和文章放在同一份内容目录里，通过相对路径引用。公开搜索会索引标题和正文，归档按年份排列。

代码块会按 Markdown 标注的语言高亮。比如在起始的三个反引号后写 `python`，再写代码，最后用三个反引号结束。省略语言时，页面会尝试自动识别。读者可通过代码块顶部的「代码语言」切换语言或选「纯文本」，该选择仅对当前浏览器中的这个代码块生效。

代码块默认显示行号。在工具栏取消勾选「行号」即可隐藏当前代码块的行号，再次勾选即可显示。浏览器会记住每个代码块的选择。点击语言选择器旁的「复制代码」，剪贴板里只有代码正文，包含原有的缩进、空行和末尾换行。复制成功后，按钮会短暂显示「已复制」。

超过 15 行的代码块默认只显示前 15 行。以 20 行代码为例，点击底部的「展开剩余 5 行」可查看全文，点击「收起至前 15 行」可恢复预览。收起时点击「复制代码」也会复制全部 20 行。

在手机上阅读长代码行时，可勾选工具栏的「自动换行」。这个开关默认关闭，浏览器会记住每个代码块的选择。一行源码即使在屏幕上分成几行，也只标一个行号。折叠仍按前 15 行源码计算，「复制代码」保留原文里的换行。

在 Joplin 桌面端，右击需要导出的笔记本，选择 **MD – Markdown + Front Matter**，保留导出的子目录和 `_resources/`。要保留笔记互链，请一起导出链接两端的笔记。随后在主题目录运行：

```sh
npm run import:joplin -- "/实际路径/Joplin导出"
npm run build
```

导入副本在本机的 `.paper-notes/imported/`，与手写的 `content/` 一起构建。下一次导入会替换上一次的导入快照。远程构建时，用同一份导出在构建机执行导入，或将适合公开的 Markdown 和附件整理进仓库的 `content/`。

## 控制文章显示和首页置顶

静态站可以在普通文章开头的 YAML 中设置两个独立的布尔值。下面的文章会显示在首页置顶区。将 `hidden` 改为 `true` 可以把它撤下。省略这两个字段时，文章默认显示并按日期排列。

```yaml
---
title: 阅读笔记
slug: reading-notes
hidden: false
pinned: true
---
```

修改后运行 `npm run build`，将新的 `dist/` 同步到网站，并清理旧版中独有的页面和附件。如果托管平台或 CDN 缓存了旧页面，还要刷新相应缓存。使用 Joplin 导出目录时，在导出的 Markdown 中设置后重新导入。隐藏会同时撤下文章直达页、站内搜索、归档和分类条目。多篇置顶文章在首页及后续分页按原发布日期排序。

启用账号服务后，站主可在「我的账户 → 文章管理」查看笔记本。和笔记分类页一样，一级目录默认展开，二级及更深的目录默认收起。点击目录名可切换展开状态。每篇文章都列在直属目录中，置顶文章排在普通文章前面，两组各自按标题排序。输入标题、目录名或完整路径可以直接展开匹配分支。勾选目录会同时选中其子目录里的文章，搜索时只选中匹配项。

站主可以逐篇或批量显示、隐藏、置顶或取消置顶。有设置变动时，服务会为整批文章自动构建。重新显示文章可恢复原网址和评论。后台设置按文章 ID 保存，每项优先于文章中对应的 YAML 字段。切换为纯静态托管前，请把要保留的显示和置顶状态写回 Front Matter，再重新构建发布。Journal 日记沿用阅读权限。[部署账号服务和验证文章设置](docs/services.md)

## 选择发布方式

| 想提供的功能 | 部署方式 |
| --- | --- |
| 公开文章、分类、标签、归档、搜索、公式和目录 | 保持 `services: false`，运行 `npm run build`，把 **`dist/` 内的文件** 发布到域名根目录。可用 COS 静态网站或其他静态主机 |
| 注册、预设头像、站主在线管理文章和用户、私有日记日历与搜索、登录后评论及回复 | 设置 `services: true`，构建后运行内置服务。需要可持久化 SQLite 文件的 Node.js 主机。参见[账号、评论与私有日记部署](docs/services.md) |

静态站可以用 `npm run preview` 在本地检查构建结果。若希望推送后自动更新，在自己的托管平台关联自己的 Git 仓库，设置生产分支为 `main`、构建命令为 `npm run build`、输出目录为 `dist`。同源的 `/posts/`、`/assets/` 等路径按域名根目录设计。

私有日记放在 `content/Journal/` 下。正文、日记专用附件和索引与公开输出隔离。网站访问权限和源码仓库的可见性是两件事：真实私人日记、Joplin 导出及服务数据库请保存在自己的私有存储中。模板附带的日记练习素材位于 `examples/diary/`。
